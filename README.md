Inclou cinc famílies de classificadors, 184 configuracions de cerca, 920 ajustos de validació creuada i 26 figures, a més de proves de preprocessament, llindars, estabilitat i errors per subgrups.

El model escollit per F1 de desenvolupament és Random Forest. En el test reservat de 179 passatgers obté accuracy **0,810** i F1 **0,742**. La memòria explica el quasi empat amb SVM i els límits d'aquesta selecció.
